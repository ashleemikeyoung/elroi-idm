# Security Policy

## Reporting a vulnerability

Report security vulnerabilities in ElRoi IdM privately through GitHub:
**Security → Report a vulnerability** on this repository
(<https://github.com/ashleemikeyoung/elroi-idm/security/advisories/new>).

Do not open public issues for security problems.

## Vulnerabilities inherited from Keycloak

ElRoi IdM is derived from Keycloak. If the problem also affects upstream Keycloak, report it to the
Keycloak project as well, following their policy:
<https://github.com/keycloak/keycloak/security/policy>.

ElRoi IdM tracks Keycloak security releases and applies upstream fixes.
